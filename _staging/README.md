# _staging

Drop zone for bulk-importing existing notes. Export from Apple Notes, Google Docs, an old Obsidian vault, spreadsheets, etc., and drop the files here. Then ask Claude to "import my staging folder" (or "process the staging folder").

Files get split into proper notes, filed into the right area with frontmatter/links/aliases, and the originals are archived to `90-Archive/_staging-originals/` — nothing is lost. This folder ends empty after each import batch.
