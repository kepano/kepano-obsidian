# Answer-style preferences

Read by the `retrieval-format` skill before every answer. Edited by the `capture-workflow` skill whenever I state a preference about answer style — that's a capture, not a conversation.

## Defaults

- Short summary first (2–4 sentences). Details only if asked.
- Bullets only when listing 3+ discrete facts; otherwise prose.
- Verbosity triggers: go detailed when the question says "everything", "in detail", "full history", or similar.
- Always end with wikilinked sources.
